## Summary
This notice explains browser/session storage and PWA caching.

## Session storage
PropertyFlow uses browser/session storage for the active login token and user experience state.

## PWA cache
The installable app caches static interface resources and the flowchart.

## No private API caching
Authenticated API responses and private tenant/owner records are not intentionally cached by the service worker.

## Offline mode
The Node service and its local store must be running for local sign-in and data changes.

## Choices
Users may clear browser storage or remove the installed app to remove locally cached shell resources.
